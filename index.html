Architecture Decision Records

  • ADR-1: Platform / Payload Separation— Clean boundary between reusable platform code and domain-specific payload logic.
  • ADR-2: Edge State Machine— Every edge agent follows a well-defined lifecycle with explicit states.
  • ADR-3: HMAC-Signed Uploads— All edge-to-headend uploads are HMAC-signed for integrity and authenticity.
  • ADR-4: Operational Trust Overrides Computational— Break-glass and human override always win over automated trust scores.
